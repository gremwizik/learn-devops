# 🐍 Snake Battle - Многопользовательская онлайн игра

Классическая игра "Змейка" с поддержкой многопользовательского режима в реальном времени через WebSocket.

## 🎮 Особенности

- **Многопользовательский режим**: Играйте с друзьями в реальном времени
- **Красивый интерфейс**: Современный дизайн с анимациями
- **Таблица лидеров**: Соревнуйтесь с другими игроками
- **Адаптивный дизайн**: Работает на всех устройствах
- **Плавная анимация**: Отрисовка на HTML5 Canvas
- **Система очков**: Собирайте еду и увеличивайте счёт

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск игры

```bash
npm run game
```

Или напрямую:

```bash
node server.js
```

### Открыть в браузере

После запуска сервера откройте в браузере:

```
http://localhost:8080
```

## 🎯 Как играть

1. **Введите имя** - Придумайте себе никнейм
2. **Нажмите "Начать игру"** - Игра начнётся автоматически
3. **Управление**:
   - Стрелки ← ↑ → ↓
   - Или клавиши W A S D
4. **Цель**: Собирайте красную еду, чтобы расти и набирать очки
5. **Избегайте**:
   - Столкновений со стенами
   - Столкновений с другими змейками
   - Столкновений с собственным хвостом

## 🏆 Система очков

- **+10 очков** за каждую съеденную еду
- Длина змейки увеличивается с каждой едой
- Соревнуйтесь за первое место в таблице лидеров!

## 🛠️ Технологии

- **Frontend**: HTML5 Canvas, Vanilla JavaScript (ES6+), CSS3
- **Backend**: Node.js, WebSocket (ws)
- **Архитектура**: Клиент-серверная модель с авторитетным сервером

## 🔧 Настройки

В файле `server.js` можно изменить:

```javascript
const PORT = 8080;           // Порт сервера
const GRID_SIZE = 30;        // Размер игрового поля
const GAME_SPEED = 100;      // Скорость игры (мс)
const FOOD_COUNT = 5;        // Количество еды на поле
```

В файле `client.js`:

```javascript
const GRID_SIZE = 20;        // Размер клетки (px)
const TILE_COUNT = 30;       // Количество клеток
const GAME_SPEED = 100;      // Скорость обновления
```

## 🌐 Многопользовательский режим

Игра автоматически поддерживает несколько игроков:

1. Запустите сервер один раз
2. Откройте игру в нескольких вкладках/браузерах
3. Все игроки будут видеть друг друга в реальном времени

### Для игры по сети:

1. Узнайте свой IP адрес:
   ```bash
   # Linux/Mac
   ifconfig | grep inet
   
   # Windows
   ipconfig
   ```

2. Другие игроки могут подключиться по адресу:
   ```
   http://ВАШ_IP:8080
   ```

## 🐛 Отладка

Если возникли проблемы:

1. **Проверьте порт**: Убедитесь, что порт 8080 свободен
2. **Консоль браузера**: Откройте DevTools (F12) для просмотра ошибок
3. **Логи сервера**: Смотрите вывод в терминале

## 🎨 Кастомизация

### Изменить цвета змеек

В `server.js` и `client.js` измените массив `colors`:

```javascript
const colors = [
    '#ff6b6b', '#4ecdc4', '#45b7d1', '#f9ca24',
    // Добавьте свои цвета
];
```

### Изменить тему

В `styles.css` измените CSS переменные:

```css
:root {
    --primary-color: #00d4aa;
    --secondary-color: #0099ff;
    --dark-bg: #1a1a2e;
    /* ... */
}
```
